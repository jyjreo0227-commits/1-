# 1페니 대학 (Penny University)

Unity 6 기반 3D 1인칭 정치 토론·추리 게임 개발 저장소입니다.

## 현재 상태

신문, 왕립 기록보관소, 추론 노트, 시나리오 및 토론 규칙의 **프로토타입 C# 코드**를 단계적으로 이관합니다.

- 기존 《바이러스의 비밀》 프로젝트와 완전히 분리된 저장소입니다.
- Unity 에디터에서 컴파일·실행 테스트를 아직 수행하지 않았습니다.
- 씬, 프리팹, UI 연결과 게임 밸런스 확정은 추후 작업입니다.
